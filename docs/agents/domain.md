# Domain Docs

엔지니어링 스킬이 코드베이스를 탐색할 때 이 레포의 도메인 문서를 어떻게 소비해야 하는지에 관한 지침.

## 탐색 전에 이것들을 읽으세요

- 레포 루트의 **`GLOSSARY.md`**: 프로젝트의 정규 도메인 용어와 피해야 할 동의어(`_Avoid_`)가 정의되어 있습니다.
- **`docs/adr/`**: 작업하려는 영역을 다루는 아키텍처 결정 기록(ADR)을 읽으세요.

## 용어집의 어휘 사용

출력이 도메인 개념을 명명할 때(이슈 제목, PR 본문, 리팩터링 제안, 가설, 테스트 이름, 코드 심볼에서), `GLOSSARY.md`에 정의된 대로 용어를 사용하세요. 용어집이 명시적으로 피하는 동의어로 흘러가지 마세요.

## ADR 충돌 플래그

출력이 기존 ADR과 모순된다면, 조용히 재정의하는 대신 명시적으로 드러내세요.
