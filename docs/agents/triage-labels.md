# Triage Labels

스킬은 다섯 개의 정규 분류 역할의 관점에서 말합니다. 이 파일은 그러한 역할을 이 레포의 이슈 트래커에서 사용되는 실제 레이블 문자열에 매핑합니다.

| mattpocock/skills에서의 레이블 | 우리 트래커에서의 레이블 | 의미                                     |
| ------------------------------- | ------------------------ | ---------------------------------------- |
| `needs-triage`                  | `needs-triage`           | 유지보수자가 이 이슈를 평가해야 함       |
| `needs-info`                    | `needs-info`             | 더 많은 정보를 위해 보고자를 기다리는 중 |
| `ready-for-agent`               | `ready-for-agent`        | 완전히 명세화됨, AFK 에이전트에 준비됨   |
| `ready-for-human`               | `ready-for-human`        | 인간 구현이 필요함                       |
| `wontfix`                       | `wontfix`                | 조치하지 않을 것                         |
